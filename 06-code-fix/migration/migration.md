# 버전 업그레이드 / 마이그레이션

> 대상 모델: Claude Code, Codex | 마지막 테스트: YYYY-MM-DD

## 언제 쓰나
- 프레임워크/라이브러리 메이저 업그레이드
- 라이브러리 교체

## 프롬프트
```text
{라이브러리} 를 {현재 버전} → {목표 버전}으로 마이그레이션해줘.

1. 공식 마이그레이션 가이드 기준 Breaking Changes 목록
2. 이 코드베이스에서 영향 받는 파일 목록
3. 단계별 마이그레이션 계획 (각 단계 후 빌드/테스트 가능한 상태 유지)
4. 실행 후 남은 경고/deprecated 항목 정리
```
