# Design Prompts

UI/UX, 랜딩페이지, 컴포넌트, 슬라이드, 이미지 등 **디자인 결과물**을 뽑아내기 위한 프롬프트 모음.

## 구성
| 파일 | 용도 |
|---|---|
| `ui-landing-page.md` | 랜딩페이지 / 웹 UI 생성 |
| (추가 예정) `design-system.md` | 디자인 토큰, 컴포넌트 규칙 |
| (추가 예정) `slides.md` | 발표자료 디자인 |
| (추가 예정) `image-gen.md` | 이미지 생성 모델용 프롬프트 |

## 작성 규칙
- 파일 상단에 **대상 모델**(Claude / GPT / Codex / Gemini 등)과 **테스트 날짜**를 적는다.
- 프롬프트 본문은 코드블록으로 감싸 복사하기 쉽게 한다.
- 가능하면 결과 스크린샷을 `assets/`에 함께 넣는다.
