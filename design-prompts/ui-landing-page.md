# UI 생성 프롬프트

- 대상 모델: Claude (Sonnet/Opus), GPT, Codex
- 출력: 단일 HTML 파일 (Tailwind CDN) 또는 React 컴포넌트
- 마지막 테스트: YYYY-MM-DD

## 프롬프트
```text
너는 시니어 프로덕트 디자이너이자 프론트엔드 엔지니어다.
아래 제품을 위한 랜딩페이지를 만들어라.

[제품] {제품명 / 한 줄 설명}
[타깃] {누구를 위한 제품인지}
[톤앤매너] {예: 미니멀, 테크, 따뜻함, 대담함}
[참고 레퍼런스] {Linear, Vercel, Stripe 등}

요구사항:
1. 섹션: Hero / 핵심 기능 3개 / 사용 사례 / 가격 / FAQ / CTA / Footer
2. 일관된 디자인 토큰(색상, 간격 4/8px 그리드, 타이포 스케일)을 먼저 정의하고 사용할 것
3. 흔한 "AI 느낌" 디자인(보라색 그라데이션 남발, 과한 이모지, 의미 없는 glassmorphism)은 피할 것
4. 반응형(모바일 우선), 접근성(대비, alt, 시맨틱 태그) 준수
5. 결과는 단일 파일로, 바로 실행 가능하게

먼저 디자인 방향을 3줄로 요약한 뒤 코드를 작성해라.
```

## 메모
- 레퍼런스 사이트를 구체적으로 줄수록 품질이 좋아짐
- "피해야 할 것"을 명시하면 뻔한 결과가 줄어듦
