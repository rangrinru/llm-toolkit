# 보안 점검

> 대상 모델: Claude Code, Codex | 마지막 테스트: YYYY-MM-DD

## 언제 쓰나
- 배포 전, 외부 공개 전, 인증/결제 코드 작성 후

## 프롬프트
```text
아래 코드(또는 저장소)를 보안 관점에서 점검해줘. 수정하지 말고 보고만.

점검 항목:
- 인증/인가 누락, 권한 상승
- 입력 검증 (SQL Injection, XSS, Command Injection, Path Traversal)
- 시크릿/키 하드코딩, 로그에 민감정보 노출
- 취약한 의존성
- CORS, CSRF, 세션/토큰 처리

출력: | 심각도 | 위치(파일:라인) | 문제 | 공격 시나리오 | 수정 방향 |
오탐 가능성이 있는 항목은 표시해줘.
```
