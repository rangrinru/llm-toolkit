# 디자인 → 모션 제작 흐름

1. **콘셉트**: 메시지, 타깃, 톤 정의
2. **스타일 정의**: [design-tokens](../../01-design/design-system/design-tokens.md)로 색상/타이포 확정
3. **스토리보드**: 장면별 내용과 타이밍표 작성
4. **제작 방식 선택**
   - 정확한 제어/데이터/자막 → [Remotion](../../02-motion-graphics/remotion/remotion-video.md)
   - 개념 설명 → [Manim](../../02-motion-graphics/manim/manim-explainer.md)
   - 실사/분위기 클립 → [AI 영상](../../02-motion-graphics/ai-video/video-gen-prompt.md)
5. **조합/편집**: 코드 영상 + AI 클립 + 사운드
6. **회고**: 잘 된 프롬프트는 해당 카테고리에 저장
