# HWP/HWPX 서식 수정

> 대상 모델: Claude (Claude Code) | 마지막 테스트: 2026-11-17
> 출처: 직접 작성 (정부 R&D 보고서 서식 문서를 한글 미설치 PC 에서 수십 번 고친 경험)

## 언제 사용하나
- `.hwp` / `.hwpx` 문서의 글·표·그림을 고쳐 달라는 요청
- 사용자가 한글 화면 캡처를 보내며 "글이 겹친다", "띄어쓰기가 벌어진다", "한 글자만 튀어나온다", "표 제목이 다음 쪽으로 넘어간다"고 할 때
- 한글 프로그램이 없는 PC 에서 HWP 내용을 읽거나 그림을 꺼내야 할 때

## 워크플로우
1. **최신본 확인** — 고치기 직전에 폴더를 다시 본다. 사용자가 한글에서 저장하면서 파일 이름을 바꾸는 일이 잦다(v6 → v7).
   마지막으로 내가 저장한 파일과 `cmp` 로 비교해, 다르면 사용자가 고친 것이므로 그 파일을 기준으로 삼는다.
2. **사본 백업** — 작업 폴더에 원본 사본을 떠 두고, 결과는 임시 파일에 먼저 만든다.
3. **HWP 면 HWPX 로** — `scripts/hwp_tools.py convert` 로 바꾼 사본을 고친다(HWP 바이너리에는 직접 못 쓴다). 원본 HWP 는 건드리지 않는다.
4. **문자열 패치** — XML 을 통째로 다시 쓰지 말고 필요한 부분만 문자열로 바꾼다(`scripts/hwpx_patch.py`). 모양(paraPr/charPr)은 원본을 고치지 말고 복제해서 바꾼다.
5. **검사** — 글 내용이 의도대로인지(서식만 고쳤으면 글은 같아야 함), 표·그림 개수, `hwpx.validate_editor_open_safety` 통과.
6. **저장 직전 다시 cmp** — 그 사이 사용자가 저장했으면 덮어쓰지 말고 다시 1번부터.
7. **보고** — 한글 화면으로 확인하지 못했다는 점, 줄 나뉨은 예측이라는 점을 함께 알린다. 사용자가 캡처로 확인해 주면 그걸 기준으로 다음 수정.

## 규칙 / 주의사항
- **절대 재생성하지 않는다.** 한 번 넘긴 파일은 사용자 것이다. 작은 요청마다 스크립트로 통째로 다시 만들면 사용자가 한글에서 고친 내용이 모두 사라진다. 재생성이 꼭 필요하면 새 이름으로.
- **줄 배치 캐시(`<hp:linesegarray>`)를 지운다.** 글을 늘리거나 표를 넣은 뒤 이걸 남겨 두면, 바뀐 문단 뒤의 글이 옛 위치에 그려져 겹친다. 문서 전체에서 지워도 한글이 열 때 다시 계산한다.
- **paraPr 의 값은 두 벌이다.** `hp:switch` 안에 `hp:case`(새 단위)와 `hp:default`(옛 단위, 값이 2배) 두 벌이 있어 한 벌만 고치면 한글에 반영되지 않는다. 정규식으로 둘 다 바꾼다.
- **같은 모양을 여러 문단이 함께 쓴다.** 원래 paraPr/charPr 를 고치면 엉뚱한 문단까지 바뀐다 → 복제(`itemCnt` +1, 새 id)해서 해당 문단만 새 id 로.
- **"효과 없었음"을 기억한다.** 한글에서 실제로 듣지 않은 설정이 있다(아래 표). 같은 수를 두 번 쓰지 않는다.
- 한글이 없으면 화면을 볼 수 없다. "됐다"고 단정하지 말고 무엇을 바꿨고 무엇을 확인 못 했는지 말한다.

## 증상 → 처방 요약

| 증상 | 원인 | 처방 | 비고 |
|---|---|---|---|
| 수정한 표 뒤 글이 표와 겹침 | 줄 배치 캐시가 옛 위치 | `hwpx_patch.py relayout` | 문서 전체 캐시 삭제 |
| 낱말 사이가 크게 벌어짐 | 양쪽 맞춤 + 긴 영문 이름이 통째로 다음 줄로 | 정렬을 LEFT 로 | `breakLatinWord=BREAK_WORD` 는 한글에서 효과 없었음 |
| 둘째 줄부터 왼쪽이 비어 보임 | 글머리표용 내어쓰기(`hc:intent` 음수)가 글머리표 없는 문단에 걸림 | intent 0 (두 벌 모두) | 글머리표 문단은 유지 |
| 끝줄에 "함." 같은 한두 글자 | 줄이 아주 조금 넘침 | 문단 자간 -1~-7 % (`Shift+Alt+N` 과 같음) | `tidy_paragraphs.py` |
| 표 칸에서 ")" 나 "1" 만 다음 줄 | 열 폭이 조금 모자람 | 다른 열에서 폭을 가져와 넓힘 | `rebalance_columns.py` |
| 표 제목과 표가 다른 쪽 | 문단이 따로 놓임 | 제목을 표의 위쪽 캡션으로 이동 | 본문이 큰 틀 표 안에 있으면 `keepWithNext` 는 효과 없었음 |
| 첫 쪽 내용이 한두 줄 넘침 | 표 행 높이 | 칸 위·아래 여백(`cellMargin top/bottom`)과 `cellSz height` 를 조금씩 줄임 | 글자 크기·줄 간격은 유지 |

## 참고 파일
- `references/hwpx-structure.md`: HWPX 파일 구조, 단위, 자주 쓰는 XML 요소와 레시피(글 바꾸기, 표 추가·열 분리, 그림 교체·삭제, 캡션, 번호 당기기)
- `references/linebreak-notes.md`: 한글 줄바꿈 관찰 결과와 예측기 정확도, 판정 기준
- `scripts/hwp_tools.py`: HWP 글 뽑기 / 그림 꺼내기 / HWPX 변환
- `scripts/hwpx_patch.py`: 문자열 패치 라이브러리 + 명령(stats, relayout, replace, caption)
- `scripts/linebreak_sim.py`: 글꼴 폭 기반 줄 나뉨 예측기
- `scripts/tidy_paragraphs.py`: 정렬·내어쓰기·자간 일괄 정리
- `scripts/rebalance_columns.py`: 표 열 너비 재분배

## 준비
```bash
# uv 사용 예 (Python 3.12)
uv run --with lxml --with pillow --with python-hwpx --with olefile python scripts/hwpx_patch.py stats 문서.hwpx
```
글꼴 폭은 Windows 글꼴 파일로 잰다. 다른 OS 면 `linebreak_sim.py` 의 `FONTFILE` 경로를 바꾼다.
