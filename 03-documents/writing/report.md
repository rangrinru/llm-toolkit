# 보고서 / 기획서 작성

> 대상 모델: Claude, GPT | 마지막 테스트: YYYY-MM-DD

## 언제 쓰나
- 보고서, 기획서, 제안서 초안을 만들 때

## 프롬프트
```text
아래 자료로 {보고서 유형}을 작성해줘.

[독자] {의사결정자 / 팀 / 외부 고객}
[목적] {승인 요청 / 현황 공유 / 제안}
[분량] {N페이지 또는 N자}

구성:
1. 한 줄 요약 (결론 먼저)
2. 배경 및 문제
3. 핵심 내용 / 분석 (수치는 표로)
4. 제안 및 기대 효과
5. 다음 단계 / 요청 사항

[자료]
{자료}
```
