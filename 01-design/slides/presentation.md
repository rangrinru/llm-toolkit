# 발표자료 구성 + 디자인

> 대상 모델: Claude, GPT | 마지막 테스트: YYYY-MM-DD

## 언제 쓰나
- 발표/피치덱 초안을 만들 때

## 프롬프트
```text
주제: {주제}
청중: {청중} / 발표 시간: {N}분 / 목적: {설득, 보고, 교육 등}

1. 먼저 핵심 메시지 1문장과 스토리라인(문제 → 해결 → 근거 → 행동 촉구)을 제안
2. 슬라이드별로 [제목(결론형 문장) / 핵심 내용 3개 이내 / 시각자료 제안] 작성
3. 한 슬라이드 = 한 메시지 원칙, 텍스트는 최소화
4. 디자인 가이드(색상 2~3개, 폰트, 레이아웃 패턴) 제안
```
