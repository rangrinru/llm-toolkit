# 랜딩페이지 UI 생성

> 대상 모델: Claude, GPT, Codex | 마지막 테스트: YYYY-MM-DD

## 언제 쓰나
- 새 제품/서비스의 랜딩페이지 시안이 필요할 때
- 단일 HTML 또는 React 컴포넌트로 바로 확인하고 싶을 때

## 프롬프트
```text
너는 시니어 프로덕트 디자이너이자 프론트엔드 엔지니어다.
아래 제품을 위한 랜딩페이지를 만들어라.

[제품] {제품명 / 한 줄 설명}
[타깃] {누구를 위한 제품인지}
[톤앤매너] {예: 미니멀, 테크, 따뜻함, 대담함}
[참고 레퍼런스] {Linear, Vercel, Stripe 등}
[색감] {바탕 · 글자 · 강조색 hex — 강조색을 쓰는 자리까지}
[폰트] {제목 / 본문 폰트 이름}
[문장 톤] {예: 해요체, 짧은 명사형} — 예) "{예문 한 줄}"

요구사항:
1. 섹션: Hero / 핵심 기능 3개 / 사용 사례 / 가격 / FAQ / CTA / Footer
2. 디자인 토큰(색상, 4/8px 간격, 타이포 스케일)을 먼저 정의하고 일관되게 사용
3. 흔한 "AI 느낌" 디자인(보라색 그라데이션 남발, 과한 이모지, 의미 없는 glassmorphism) 금지
4. 모바일 우선 반응형, 접근성(대비, alt, 시맨틱 태그) 준수
5. 단일 파일로, 바로 실행 가능하게

먼저 디자인 방향을 3줄로 요약한 뒤 코드를 작성해라.
```

## 메모
- 레퍼런스 사이트를 구체적으로 줄수록 품질이 좋아짐
- 색은 hex로, 폰트는 실제 이름으로, 톤은 예문으로 주면 결과가 더 정확해짐 → [프롬프트 품질 요소](../references/prompt-elements.md)
