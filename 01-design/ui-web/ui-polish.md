# 기존 UI 폴리싱

> 대상 모델: Claude, GPT | 마지막 테스트: YYYY-MM-DD

## 언제 쓰나
- 이미 만든 화면이 어딘가 어색할 때
- 스크린샷이나 코드를 주고 개선안을 받고 싶을 때

## 프롬프트
```text
첨부한 화면(스크린샷/코드)을 시니어 디자이너 관점에서 점검해줘.

1. 문제점을 [정렬/간격, 타이포, 색상/대비, 위계, 일관성, 접근성] 기준으로 나열
2. 각 문제의 영향도(상/중/하)와 구체적인 수정값(px, 색상 코드, font-weight 등)
3. 수정된 코드 전체

기능과 구조는 바꾸지 말고 시각적 품질만 개선해.
```
