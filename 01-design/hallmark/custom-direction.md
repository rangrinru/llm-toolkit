# Custom: 테마 없이 나만의 페이지

> 출처: [hallmark references/direction.md](https://github.com/Nutlope/hallmark/blob/main/skills/hallmark/references/direction.md)
> "custom", "bespoke", "no theme", "derive it"이라고 요청할 때만 쓰는 경로. 바닥 규칙, 게이트, 최종 검사만 유지하고 나머지는 전부 디자이너의 결정.

## 목표
**템플릿을 다 거절한 고객에게 디자인 리드가 가져갈 페이지.** 처음 만들어 보는 것, 다른 프롬프트로는 나올 수 없는 것, 디자이너가 두 번 보게 되는 것.

- **독특함 = 구체성.** 큰 결정은 모두 이 고객만의 것(주제, 장소, 재료, 숫자, 사람들의 말투). 경쟁사 이름을 넣어도 말이 되면 아직 부족하다.
- **깔끔함 = 비어있음이 아니라 정확함.** 눈에 보이는 시스템(서로 크게 다른 몇 개의 글자 크기, 한 가지 간격 리듬, 맞춰진 가장자리). 모든 요소가 역할을 한다.
- **꽉 찬 것이 기본.** 히어로와 샘플이 아니라 사이트 전체. 보통 6~9개 섹션, 각각 볼 만한 것을 중심으로. 제목과 문단만 있는 섹션은 미완성.
- **자유는 자유.** 다크든 라이트든, 한 색이든 네 색이든, 아이디어가 원하면 어떤 길이든.

## 코드 쓰기 전 5단계
1. **주제를 배운다.** 이 고객만 가진 것: 이름과 의미, 장소의 모습, 한 단어로 하는 일, 실제 숫자, 영업시간과 의식, 고객이 쓰는 단어.
2. **어차피 만들었을 페이지를 버린다.** 생각 없이 나올 페이지와 그 뻔한 변형은 둘 다 안 된다. 보통은: 왼쪽 제목 + 오른쪽 그림 히어로, 번호 붙은 3단계, 헤어라인 사이 라벨-값 행, 폼이 있는 마무리 밴드, 거대한 워드마크 아래 다크 푸터, 작은 회색 라벨, 옅은 배경에 조심스러운 강조색 하나. **이 중 2개가 계획에 있으면 그건 템플릿이다.**
3. **넓게 펼치고 고른다.** 최대한 다른 방향 3개를 각 두 줄로(아이디어, 구성, 룩). 가장 안전한 것이 아니라 디자인 리드가 싸워서라도 지킬 것을 고른다.
4. **아이디어가 페이지를 이끈다.** 이 고객에게만 맞는 생각 하나가 위에서 아래까지 결정한다. 히어로에서 멈추는 아이디어는 "히어로만 좋은 템플릿".
5. **콘텐츠가 구조를 만든다.** 방문자가 보고, 이해하고, 해야 할 것을 순서대로 정하고 각각에 가장 잘 보이는 형태를 준다.

## 이미 소모된 것들 (보는 즉시 거절)
- 크림/베이지 배경 + 고대비 세리프 + 클레이 강조색 / 거의 검정 + 네온 강조 하나 / 옅은 배경 + 소심한 강조 하나 / 보라→파랑 / 업종 색(소프트웨어 = 파랑, 헬스 = 초록)
- 제일 먼저 떠오르는 서체들
- 가운데 제목 + 카드 3개, 히어로 → 기능 → CTA → 푸터 흐름, 습관적인 보조 버튼
- 주제를 아는 대신 칠한 것: 종이/그레인 질감, 도장, 장식용 다이얼, 베벨, 판화풍, 사물 그림
- 아이브로우, 자간 넓힌 대문자, 모노 라벨, 제목 속 강조 단어, 가운뎃점 문자열

## 그림
보여줄 것이 있을 때만. 장소, 음식, 일하는 사람, 물건, 공예 → 사진(적게, 크게, 출처 표기). 소프트웨어 → 실제로 동작하는 제품. 서비스, 아이디어, 글 → 활자와 색만으로 충분하고 그게 맞는 경우가 많다.
**삭제 테스트**: 그 그림을 지웠을 때 페이지가 사실 하나를 잃는가? 분위기용 그림은 뺀다.

## 글
카피는 디자인의 절반이고, 생성된 페이지가 가장 먼저 티 나는 곳.
- 고객이 쓰는 명사, 모든 제목에 사실 하나, 경쟁사가 그대로 쓸 수 있는 문장 금지, 화면당 약 80단어
- "짧게 끊은 두 조각"(예: "Fast. Simple.") 헤드라인은 모든 모델이 쓰는 형태
- 제목만 이어 읽었을 때 이 고객의 이야기가 되어야 한다

## 범용 프롬프트로 쓰기
```text
테마나 템플릿 없이 {고객/제품}만을 위한 페이지를 디자인해줘.
1. 코드 전에: 이 고객만 가진 것(이름의 의미, 장소, 숫자, 고객의 언어)을 정리해.
2. 아무 생각 없이 만들었을 페이지를 먼저 묘사하고, 그건 쓰지 마.
3. 최대한 다른 방향 3개를 각 두 줄로 제시하고, 가장 과감하지만 설득력 있는 것을 골라 이유를 말해.
4. 하나의 아이디어가 히어로부터 푸터까지 이끌게 해.
5. 크림+세리프+테라코타, 보라-파랑 그라데이션, 가운데 제목+카드 3개, 아이브로우 라벨은 금지.
6. 수치, 후기, 로고는 내가 준 것만 사용.
```
