# The Floor: 16개 바닥 규칙

> 출처: [hallmark SKILL.md](https://github.com/Nutlope/hallmark/blob/main/skills/hallmark/SKILL.md) § The Floor
> 모든 출력에 적용되고, 어떤 이유로도 예외 없음. 괄호 안 숫자는 원본 게이트 번호.

| # | 규칙 | 게이트 |
|---|---|---|
| 1 | 모든 색상과 폰트는 `:root`(또는 테마 블록)에 선언한 **토큰으로만** 사용. 토큰 블록 밖에 색상값이나 `font-family` 직접 쓰기 금지 | 48 |
| 2 | `transition: all` 금지. `width`, `height`, `top`, `left` 애니메이션 금지 (`transform`, `opacity`만) | 10a |
| 3 | 정자체 제목 안에 **한 단어만 이탤릭** 금지 | 38i |
| 4 | `html`, `body` 모두 `overflow-x: clip`. `hidden`이나 `100vw` 금지 | 34 |
| 5 | 이미지가 들어가는 그리드 트랙은 `minmax(0, 1fr)`, 큰 제목은 `overflow-wrap: break-word; min-width: 0` | 50 |
| 6 | 모든 인터랙티브 요소에 `:focus-visible`, **즉시** 표시 (페이드 금지) | 26a, 15 |
| 7 | 모든 애니메이션에 `prefers-reduced-motion: reduce` 대응, 스크립트가 꺼져도 콘텐츠가 보여야 함 | 27, 62 |
| 8 | **지어낸 수치, 후기, 로고 월, 고객사 수 금지** | 46a |
| 9 | **아이브로우(제목 위 작은 라벨) 금지.** 라벨, 캡션, 표 헤더, 태그, 내비 링크를 자간 넓힌 대문자나 스몰캡으로 쓰지 말 것. 본문 서체로 한 단계 작게, 문장형 대소문자, 자간 기본값 | 54, 67 |
| 10 | 가운뎃점으로 이은 메타 문자열(`A · B · C`), 링크 텍스트에 붙은 화살표(`Learn more →`), 장식용 상태 점 금지 | 63 |
| 11 | 보라→파랑 그라데이션, 카드 안의 카드, 아이콘 대신 이모지, 직접 그린 브라우저/OS 창 금지 | 2a, 4, 30a, 47a |
| 12 | 히어로의 제목, 한 문장 설명, 주요 버튼이 **1280 x 800에서 스크롤 없이** 모두 보여야 함 | 44b |
| 13 | 한 화면에 **약 80단어**. 히어로 텍스트는 제목 + 한 문장 + 버튼 | 58 |
| 14 | 컨테이너 최대폭을 정하고 가운데 정렬. 1920에서는 여백만 늘어나고 본문 폭과 그리드는 그대로 | 44d |
| 15 | CSS 첫 줄은 Hallmark 스탬프(어떤 결정을 했는지 기록), 그다음 자기 비평 한 줄, 예외 사항 | 20 |
| 16 | Node가 있으면 넘기기 전에 `sloplint.mjs <output> --render` 실행. FAIL은 모두 수정, REFLEX는 수정하거나 예외 처리 | - |

## 스킬 없이 쓸 때 (CLAUDE.md / AGENTS.md에 붙여넣기용)
```markdown
## UI 디자인 바닥 규칙
- 색상/폰트는 :root 토큰으로만. 하드코딩 금지.
- transition: all 금지, transform/opacity만 애니메이션. prefers-reduced-motion 대응 필수.
- 제목 위 아이브로우 라벨, 자간 넓힌 대문자 라벨, 제목 속 한 단어만 다른 색/이탤릭 금지.
- "A · B · C" 메타 문자열, "Learn more →" 화살표, 장식용 점 금지.
- 보라-파랑 그라데이션, 카드 안의 카드, 이모지 아이콘, 가짜 브라우저 창 금지.
- 수치, 후기, 로고는 내가 준 것만. 없으면 비워둘 것.
- 히어로: 제목(7단어 이하) + 한 문장(12단어 이하) + 버튼 1~2개, 1280x800에서 한 화면 안에.
- 한 화면 약 80단어. 모든 인터랙티브 요소에 즉시 보이는 :focus-visible.
- html, body에 overflow-x: clip. 컨테이너는 최대폭 지정 후 가운데 정렬.
```
