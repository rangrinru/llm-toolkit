# 50개 테마 카탈로그

> 출처: [hallmark references/themes/](https://github.com/Nutlope/hallmark/blob/main/skills/hallmark/references/themes) | 미리보기: https://www.usehallmark.com
> 테마는 **재료(material)**다: 종이(배경), 잉크, 서체, 표면, 컨트롤, 모션, 말투만 정하고 섹션 구성이나 순서는 정하지 않는다.

## 헤더 필드 읽는 법
| 필드 | 의미 |
|---|---|
| 배경 | 배경 밝기 구간 (밝음 L>85 / 중간 30~85 / 어두움 <30) |
| 디스플레이 | 제목 서체 (분류 + 서체명) |
| 강조색 | warm(10~60°), cool(200~300°), neutral, chromatic-<색> |
| posture | 색을 쓰는 강도: restrained(절제) < committed < full-palette < drenched(배경 전체를 색으로) |

## 테마를 직접 지정하는 법
```text
/hallmark <만들 페이지 설명>, theme: cobalt
```

## 메모
- 테마 파일 하나는 8KB 이하. 빌드할 때는 선택한 테마 파일 하나만 읽는다.
- 테마 파일 구조(직접 테마를 만들 때 참고): 한 문단 소개 → OKLCH 토큰 → 타이포 → 표면 → Range(사진 없이 만드는 섹션) → 컨트롤 → 모션 → 말투 → 금지 사항 → 20줄 이하 CSS 힌트
