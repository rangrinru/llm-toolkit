# AI 티 체크리스트 (Gates 요약)

> 출처: [hallmark references/gates.md](https://github.com/Nutlope/hallmark/blob/main/skills/hallmark/references/gates.md) § 4
> 등급: **F** = Floor(배포 불가) / **R** = Reflex(이유 있으면 예외 가능). 괄호는 게이트 번호.

## 색과 표면
- [ ] **F** 보라→파랑, 보라→분홍, 어두운 배경의 시안 그라데이션 (2a) → 기준 색 하나, 단색
- [ ] **R** 그라데이션 텍스트 (2b) → 단색, 굵기나 디스플레이 서체로 강조
- [ ] **F** 토큰 밖에서 순수 #000 / #fff 사용 (7a) → 기준 색 쪽으로 살짝 틴트
- [ ] **R** 강조색이 화면의 약 5% 초과 (23) → 줄이거나 의도(posture)를 명시
- [ ] **R** 오로라/메시 블롭, 떠다니는 흐린 원, 방사형 후광, 다크 배경의 컬러 글로우 (29)
- [ ] **R** "크림 배경 + 고대비 세리프 + 테라코타 강조색" 조합 (65) → 가장 흔한 AI 룩
- [ ] **R** Tailwind 기본 팔레트(indigo-500, violet-600, slate-900 등) 그대로 사용 (74)

## 타이포그래피
- [ ] **R** 디스플레이 서체로 Inter, Roboto, Open Sans, Poppins, Lato, 시스템 폰트 (1)
- [ ] **R** 본문 줄 길이가 45~75자 범위를 벗어남 (25)
- [ ] **R** 폰트 패밀리 3개 초과 (37)
- [ ] **F** 정자 제목 속 한 단어만 이탤릭 (38i)
- [ ] **R** 제목 속 한 단어만 색/굵기/하이라이트/밑줄로 강조 (38iii)
- [ ] **F** 줄바꿈될 수 있는 대문자 제목의 line-height가 1.0 미만 (55a)
- [ ] **R** 코드가 아닌데 라벨/캡션/메타에 모노스페이스 사용, "모노 코스프레" (64)
- [ ] **R** 본문 12px 미만, 여러 줄 본문 행간 1.3 미만 (75) → 본문 16px, 행간 1.5~1.65
- [ ] **F** 15px 이하 라벨/태그/내비를 대문자나 자간 0.03em 초과로 (67)

## 구조와 레이아웃
- [ ] **R** 아이콘-제목-설명 카드 3개 균등 배치, 카드 왼쪽의 굵은 컬러 줄 (3)
- [ ] **F** 카드 안의 카드 (4)
- [ ] **F** 히어로를 `vh`로 지정 (6a) → `dvh` / `svh`
- [ ] **R** 제목, 설명, 버튼, 로고가 전부 가운데 한 축에 쌓인 히어로 (6b)
- [ ] **R** "히어로 → 기능 3개 → CTA → 푸터" AI 템플릿 (8)
- [ ] **R** 모든 섹션을 같은 방식, 같은 간격으로 구분 (9)
- [ ] **F** 간격 토큰이 있는데 padding/margin/gap에 직접 값 (24a)
- [ ] **F** 320~1920 어느 폭에서든 가로 스크롤 (34)
- [ ] **F** 1280x800에서 히어로의 제목, 설명, 버튼, 시각 요소가 한 화면에 안 들어옴 (44b)
- [ ] **F** 1920에서 컨테이너 최대폭 없음, 그리드 열이 늘어남 (44d)
- [ ] **F** 한 화면(900px)에 약 80단어 초과 (58)
- [ ] **R** 1440에서 섹션 간격 120px 미만이거나 모두 동일 (59)
- [ ] **R** 제목이 아래 내용보다 위 내용에 더 가까움 (71), 박스 안 텍스트 여백 부족 (72)
- [ ] **R** 히어로 아래에 내용 없이 얇은 섹션, 1440에서 h2가 40px 미만 (77, 78)
- [ ] **R** 사물/식물/사람을 SVG로 그린 일러스트 (80), 그라데이션만 칠한 빈 이미지 칸 (81)
- [ ] **R** 수량을 같은 모양 점/막대 24개 이상으로 표현 (82)
- [ ] **R** 사진이 페이지의 1/3 이상을 덮어 스톡 갤러리처럼 보임 (83)
- [ ] **R** 실제 제품이 있는데 div로 가짜 제품 UI를 그림 (84) → 실제 스크린샷 캡처
- [ ] **R** 마지막 섹션이 습관적인 이메일 구독 폼 (85)

## 내비, 푸터, 카피
- [ ] **F** Jane Doe, Acme 같은 플레이스홀더, seamless/robust/empower/supercharge/elevate/unlock/next-generation 같은 버즈워드 (19)
- [ ] **R** "로고 왼쪽, 링크 가운데, 버튼 오른쪽" AI 내비 / "링크 4열 + SNS + 저작권" AI 푸터를 아무 이유 없이 사용 (42)
- [ ] **F** 지어낸 수치, 후기, 로고 월, 고객사 수 (46a)
- [ ] **F** 신호등 버튼 달린 가짜 브라우저 바, OS 창 (47a)
- [ ] **R** 폰/노트북/터미널 프레임 여러 개 (47b), 스타일 div로 만든 가짜 제품 화면 (47c)
- [ ] **F** 아이브로우: 제목 위 "TRUSTED BY", "FEATURES" 같은 작은 안내 문구 (54)
- [ ] **F** `A · B · C`, `Learn more →`, 장식 상태 점 (63)
- [ ] **R** 의미 없는 세로 회전 텍스트, 스크롤 유도 표시, 히어로의 BETA/버전 배지, 날씨/도시 띠 (66)
- [ ] **R** 빈 이미지 슬롯 5개 초과, 한 줄에 4개 이상 (68)
- [ ] **R** 같은 사실(가격 등)을 4개 이상 섹션에서 반복 (69)
- [ ] **F** 실제 전송 없이 "Sent", "Thanks"를 띄우는 가짜 폼 (70)

## 모션과 인터랙션
- [ ] **F** `transition: all`, width/height/top/left 애니메이션 (10a)
- [ ] **R** 모든 카드에 같은 hover lift, 이미지 hover 확대/회전, 비인터랙티브 요소 hover (11)
- [ ] **R** UI 상태 변화에 bounce/overshoot easing (12) → exponential ease-out
- [ ] **F** 페이드 인되는 포커스 링 (15), 툴팁 포커스 지연 = 호버 지연 (17)
- [ ] **F** 자동 회전 콘텐츠에 hover/focus 일시정지 없음 (18)
- [ ] **F** `:focus-visible` 없음, 포커스 링 대비 3:1 미만 (26a)
- [ ] **R** `:active`, `:disabled` 상태 누락 (26b) → 컨트롤은 8가지 상태 모두
- [ ] **F** reduced-motion 대응 없음 (27), JS 없으면 콘텐츠가 숨겨진 채로 남음 (62)
- [ ] **F** 상태마다 input 테두리 두께가 변함, border로 만든 포커스 링, opacity만으로 disabled 표시 (39a)
- [ ] **R** 마케팅 페이지 컨트롤 높이가 44~52px 범위 밖 (39b)

## 에셋과 접근성
- [ ] **F** 아이콘 대신 이모지 (30a), **R** 아이콘 라이브러리 2개 혼용 (30b)
- [ ] **F** 장식용 svg/canvas에 `aria-hidden`이나 라벨 없음 (33)
- [ ] **F** 깨진 이미지, 출처 표기 없는 라이브러리 사진, 유료 스톡 사진 (76)
- [ ] **F** 다른 요소에 가려진 텍스트 (73)
- [ ] **F** 대비 부족: 본문 4.5:1, 큰 텍스트, 아이콘, 포커스 링 3:1 (40, 41)
- [ ] **F** 버튼 라벨이나 주요 내비 링크가 줄바꿈됨 (49a)

## 에이전트에게 점검 맡기기

이 페이지를 위 체크리스트(01-design/hallmark/ai-slop-gates.md) 기준으로 점검해줘.
수정하지 말고, 걸리는 항목을 | 등급(F/R) | 게이트 | 위치 | 문제 | 수정 방법 | 표로 정리해.
F 항목은 모두 고쳐야 하고, R 항목은 고칠지 예외로 둘지 이유와 함께 제안해.
