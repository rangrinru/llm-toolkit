# 스타일 키워드 / 레퍼런스

## 웹 UI 레퍼런스
| 사이트 | 특징 |
|---|---|
| Linear | 다크, 미니멀, 정교한 타이포 |
| Vercel | 흑백 대비, 개발자 친화 |
| Stripe | 그라데이션, 고급스러운 일러스트 |
| Apple | 여백, 큰 타이포, 제품 중심 |

## 스타일 키워드
- 미니멀: minimal, clean, whitespace, monochrome
- 테크: dark mode, grid, monospace, subtle glow
- 따뜻함: warm tones, rounded, soft shadow, hand-drawn
- 대담함: bold typography, high contrast, brutalism

## 스타일 사조 · 은유 (구조까지 바꾸는 키워드)
형용사보다 이름 있는 스타일이나 은유 하나가 그리드 · 글꼴 · 색 규칙을 통째로 정해 준다.

| 키워드 | 따라오는 것 |
|---|---|
| 스위스 타이포그래피 (International Typographic Style) | 12단 그리드, 왼쪽 정렬, 큰 숫자, 강조 1색, 장식 없음 |
| 에디토리얼 (잡지 펼침면) | 세리프 큰 제목, 넓은 여백, 목차형 목록, 인용구 |
| 블루프린트 (공학 도면) | 남색 바탕 + 흰 선 + 모눈, 표제란, 고정폭 코드 |
| 지하철 노선도 | 역 = 단계, 노선 색 = 구분, 환승역 = 갈래 |
| 산업 안전 표지 | 노랑 + 검정 두 색, 사선 띠, 굵은 고딕, 지시문 |
| 터미널 로그 | 검정 + 형광 1색, 고정폭, 줄 단위 |
| 미니멀 모노톤 | 무채색, 굵기 · 크기로만 위계, 넓은 빈 공간 |
| 파스텔 스티커 | 칸마다 다른 파스텔, 살짝 기울어진 카드, 둥근 굵은 글꼴 |
