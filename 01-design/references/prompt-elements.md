# 디자인 프롬프트 품질 요소

> 대상 모델: Claude / GPT / Gemini | 마지막 테스트: 2026-11-16
> 출처: 직접 작성 — 같은 내용을 프롬프트만 바꿔 시안 11개를 뽑아 비교한 결과

## 한 줄 요약
"깔끔하게"는 아무것도 정하지 않는다. **용도 · 읽히는 순서 · 스타일 이름 · 숫자 제약 · 금지 목록 · 예문**을 적어야 결과가 달라진다.

## 품질을 올리는 10가지
| 요소 | 왜 효과가 있나 | 예시 문구 |
|---|---|---|
| 1. 용도 · 크기 · 노출 시간 | 글자 크기, 정보량, 대비의 기준이 정해짐 | "교육 영상 한 장면, 1600×900, 5초 노출" |
| 2. 보는 사람 | 용어 수준, 설명할 범위가 정해짐 | "처음 쓰는 현장 엔지니어" |
| 3. 읽히는 순서(위계) | 가장 차이가 큼. 없으면 모든 요소가 같은 무게로 나옴 | "단계 번호 → 단계 이름 → 직접/자동 순으로 읽히게" |
| 4. 이름 있는 스타일 | 한 단어에 그리드 · 글꼴 · 색 · 여백 규칙이 통째로 따라옴 | 스위스 타이포그래피, 에디토리얼, 블루프린트, 브루탈리즘 |
| 5. 은유 | 스타일보다 강함 — 구조 자체가 바뀜 | "지하철 노선도", "공정 라인", "계기판" |
| 6. 숫자 제약 | '깔끔'은 사람마다 다르지만 숫자는 그대로 지켜짐 | "색은 흰 · 검정 + 1색", "본문 16px 이상", "선 굵기 12px" |
| 7. 금지 목록 | 모델의 기본 버릇을 끊음 | "그림자 · 둥근 카드 · 아이콘 · 그라데이션 금지" |
| 8. 실제 내용 전부 | 안 주면 빈칸이 생기거나 지어낸 내용이 들어감 | 항목마다 '어디서 · 결과물 · 직접/자동'까지 |
| 9. 강조할 한 문장 | 화면에 초점이 생김 | "'두 단계는 저절로 넘어간다'를 인용구처럼" |
| 10. 여러 시안일 때 다르게 할 축 | 비슷한 시안 여러 개를 막음 | "시안마다 은유를 다르게: 노선도 / 도면 / 잡지" |

## 색감 · 폰트 · 문장 톤을 적는 법
- **색**: 색 이름이 아니라 **hex + 쓰는 자리**까지 적는다.
  예) `살구 바탕 #FFF4EC, 강조 코랄 #E8613C는 숫자와 '자동' 표시에만, 글자 #3B2A20`
- **폰트**: 실제 폰트 이름(한글은 Google Fonts 이름)과 쓰는 곳(제목 / 본문 / 숫자)을 적는다.
  예) `제목 Jua, 본문 Gowun Dodum` · `숫자 Hahmlet 200, 글자 Noto Sans KR 300·500`
- **문장 톤**: 톤 이름만 쓰지 말고 **예문을 하나** 붙인다.
  예) `해요체 — "저장이 끝나면 알아서 바뀌어요"` · `보고서체 — "저장 종료 시 자동 변환됨"`
- **레이아웃**: 비율 · 개수 · 크기를 숫자로 적는다.
  예) `왼쪽 40% 제목, 오른쪽 60% 목록` · `화면 70%는 비움`
- **금지**: 그 스타일을 깨는 요소를 적는다.
  예) 미니멀이면 `박스 · 배경 칩 · 아이콘 · 색 금지`

## 효과 없는 말 → 바꿔 쓸 말
| 효과 없는 말 | 바꿔 쓸 말 |
|---|---|
| 깔끔하게 | "흰 바탕 + 검정 + 강조 1색, 그림자 금지, 여백 8px 배수" |
| 세련되게 | "스위스 타이포그래피, 12단 그리드, 왼쪽 정렬, 큰 숫자" |
| 모던하게 | "IBM Plex Sans KR 400/700, 모서리 12px, 무채색 + 강조 1색" |
| 예쁘게 | 스타일 이름 + 색 hex + 폰트 이름 |
| 친근하게 | "해요체, 예) '…하면 알아서 돼요'" |
| 눈에 띄게 | "제목 72px 900, 배경 대비 7:1 이상, 강조는 한 곳에만" |

## 메모 (결과, 팁, 실패 사례)
- 모호한 프롬프트("깔끔하게 만들어줘")는 **가운데 정렬 · 같은 카드 5장 · 아이콘 · 보라 강조**로 수렴했고, 직접/자동이나 결과물 같은 정보는 빠졌다.
- 결과가 평범할 때는 형용사를 더 붙이는 것보다 **[금지]를 늘리는 쪽**이 효과가 컸다.
- 폰트 이름 하나가 인상을 가장 크게 바꾼다(같은 내용이라도 Jua / Black Han Sans / Hahmlet은 전혀 다른 화면이 됨).
- 문장 톤은 예문 1개가 "친근하게" 같은 형용사 열 개보다 정확했다.
