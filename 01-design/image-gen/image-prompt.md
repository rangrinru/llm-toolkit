# 이미지 생성 프롬프트 공식

> 대상 모델: Midjourney, GPT Image, Imagen, Flux | 마지막 테스트: YYYY-MM-DD

## 언제 쓰나
- 일러스트, 사진, 썸네일, 목업 이미지가 필요할 때

## 프롬프트
```text
[주제] {무엇을}
[구도] {클로즈업 / 와이드 / 탑뷰 / 3/4 앵글}
[스타일] {사진, 3D 렌더, 플랫 일러스트, 수채화 등}
[조명] {자연광, 스튜디오, 골든아워, 네온}
[색감] {파스텔, 고대비, 모노톤}
[카메라/디테일] {35mm, 얕은 심도, 고해상도}
[제외] {텍스트, 워터마크, 왜곡된 손}
[비율] {16:9 / 1:1 / 9:16}
```

## 메모
- 한 번에 완벽하게 쓰기보다 결과를 보고 한 요소씩 바꿔가며 개선
