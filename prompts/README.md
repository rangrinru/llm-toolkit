# Prompts

일상/업무에서 자주 쓰는 **범용 프롬프트** 모음. 카테고리별로 파일을 나눠 관리.

## 카테고리
| 폴더/파일 | 내용 |
|---|---|
| `coding.md` | 코드 리뷰, 리팩토링, 디버깅 |
| (추가 예정) `writing.md` | 글쓰기, 요약, 번역 |
| (추가 예정) `research.md` | 리서치, 비교 분석 |
| (추가 예정) `system-prompts/` | 커스텀 GPT / Project용 시스템 프롬프트 |

## 템플릿
새 프롬프트는 [`../templates/prompt-template.md`](../templates/prompt-template.md) 형식을 따른다.
