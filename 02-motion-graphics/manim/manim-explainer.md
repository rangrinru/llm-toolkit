# Manim 개념 설명 애니메이션

> 대상 모델: Claude, GPT | 마지막 테스트: YYYY-MM-DD

## 언제 쓰나
- 수학, 알고리즘, 개념을 시각적으로 설명하는 영상이 필요할 때

## 프롬프트
```text
Manim Community Edition으로 "{개념}"을 설명하는 애니메이션을 만들어줘.

1. 먼저 설명 흐름을 3~6단계로 나눠 제시
2. 각 단계를 하나의 Scene 메서드로 구현
3. 텍스트는 짧게, 시각적 변환(Transform)으로 개념을 보여줄 것
4. 실행 명령어 포함 (예: manim -pqh file.py SceneName)
```
